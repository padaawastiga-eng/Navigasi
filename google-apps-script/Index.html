Deploy ke Google Apps Script

Buat Web App mandiri Anda tanpa server atau biaya hosting!

Panduan Cara Deploy 3 Menit:

  1. Buka Google Apps Script (script.google.com) & buat Project Baru.
  2. Ganti isi file bawaan Code.gs dengan menyalin teks kode di bawah ini.
  3. Buat file HTML baru bernama Index (ketik "Index" tanpa .html), lalu salin isi Index.html ke dalamnya.
  4. Klik tombol Terapkan (Deploy) di bagian atas → Penerapan Baru (New Deployment).
  5. Pilih Jenis penerapan: Aplikasi Web (Web App).
  6. Setel Akses (Who has access): Siapa saja (Anyone).
  7. Klik Terapkan dan Anda akan mendapatkan URL Web App publik Anda!
